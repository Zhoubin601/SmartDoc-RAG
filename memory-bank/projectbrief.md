# 项目长期背景与要求

## 1. 课程与项目信息
- **课程名称**：开源软件构建技术
- **项目主题**：第七章 智能应用开发
- **作业满分**：100 分

## 2. 核心考核点
- 基于 LangChain 框架。
- 支持在线大模型或离线大模型。
- 最终交付智能应用的 README 文档说明，并附带开源仓库链接。

## 3. 已确认设计结论（2026-10-29 用户确认）
- **应用主题**：SmartDoc-RAG 智能文档知识库助手。
- **架构实现**：
  - 框架：LangChain (LCEL 架构)
  - 交互界面：Streamlit Web UI
  - 向量存储：Chroma / FAISS
  - 模型接入：在线大模型 API（标准 OpenAI 兼容接口，支持 DeepSeek、通义千问、OpenAI 等）
- **交付目标**：
  - 智能应用完整源码
  - 专业规范的 README.md（含系统架构、运行指引、开源仓库链接等）
  - 过程文档存入 `docs/`，正式交付物统一存入 `output/`

## 4. 工程管理原则
- 遵循严谨的协作规范：`raw/` -> `docs/` -> 用户确认 -> `output/`。
- 不修改原始资料，过程留痕，代码与文档严格符合开源工程标准。
