## 2. 备选方案构思与评估

### 方案 A（推荐）：SmartDoc-RAG —— 多模态文档智能检索与问答助手
- **核心定位**：基于 LangChain 经典 RAG（检索增强生成）范式构建的个人/团队文档智能知识库。
- **主要功能**：
  1. 文档解析与向量化：支持 PDF、Markdown、TXT 等格式文档上传与自动分块。
  2. 灵活向量存储：基于轻量嵌入式向量库 ChromaDB / FAISS，无需繁杂外部数据库安装。
  3. 双模式模型支持：
     - 在线模型：兼容 OpenAI / DeepSeek / 通义千问（DashScope）等。
     - 离线模型：支持本地 Ollama（如 `qwen2.5:7b` / `llama3`）。
  4. 交互式界面：基于 Streamlit 构建现代化 Web 交互界面，支持流式输出与答案知识溯源。
- **方案优势**：
  - 紧密贴合 LangChain 核心优势组件（Loaders, Splitters, Embeddings, VectorStores, Chains/LCEL）。
  - 界面与功能直观，演示效果极佳，极容易在课程评审中拿高分。

### 方案 B：OmniAgent —— 智能多工具自主分析研究助手
- **核心定位**：基于 LangChain Agent 架构的自主任务规划与研究助手。
- **主要功能**：
  1. 工具调用（Tool Calling）：集成搜索（DuckDuckGo/Tavily）、数学计算、代码解释器。
  2. 任务自主拆解：基于 ReAct 模式思考链（Reasoning + Action）。
  3. 输出结构化调研报告并支持导出。
- **方案优势**：
  - 体现高阶 Agentic 流程，算法与逻辑深度高。
  - 外部依赖相对轻量。

### 方案 C：GitAudit-AI —— 智能开源代码走查与重构顾问
- **核心定位**：结合课程《开源软件构建技术》主题，针对开源代码仓库进行自动化评审、安全审计与代码重构建议。
- **主要功能**：
  1. 本地代码仓库或单文件静态提取与分析。
  2. 基于 LangChain 审查链对代码质量、潜在漏洞、开源协议合规性进行分析。
  3. 生成 Markdown 格式的审查报告。
