## 3. 阈值选择依据

根据本次运行的 Q1~Q10 实测 Top-1 余弦相似度分布：
- **文档内有效问题（Q1~Q8）**：Top-1 相似度分布在 `0.1678 ~ 0.3823` 之间；
- **含局部通用词重合的文档外问题（Q9）**：Top-1 相似度为 `0.1104`（落入 `[0.08, 0.15)` 低相关度预警区间时，系统注入预警提示，由模型判断是否拒答）；
- **完全无关的文档外问题（Q10）**：Top-1 相似度为 `0.0553`（低于 `0.08` 时在检索格式化阶段直接触发拒答提示）。

阈值 `0.08` / `0.15` 依据上述样例分布选取；样例规模较小，更换语料后应重新运行本脚本校准。
