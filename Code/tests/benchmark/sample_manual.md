# SmartDoc-RAG 知识库服务运维与开发技术手册

## 第一节：服务架构与基础端口配置

SmartDoc-RAG 采用前后端一体化的流式交互架构。系统核心组件在启动时监听以下网络端口：
- **Web 交互网关端口**：默认监听 `8501` 端口，提供文档上传、参数配置与流式问答界面。
- **内部 RPC 通信端口**：默认监听 `9090` 端口，用于分布式节点间的索引状态同步。
- **Prometheus 监控指标端口**：默认监听 `9100` 端口，暴露 `/metrics` 接口供监控系统抓取检索延迟与内存占用。

## 第二节：数据库连接与连接池策略

元数据存储采用 PostgreSQL 15 关系型数据库。生产环境连接池关键参数配置如下：
- 数据库默认管理员账号：`db_operator`
- 最大连接池容量（`max_connections`）：默认设置为 `120`
- 空闲连接回收超时时间（`idle_timeout`）：默认设置为 `300` 秒
- 连接获取最大等待时间（`connection_timeout`）：`15` 秒

## 第三节：文档解析与分块策略

系统文档加载器（Document Loader）支持四种主流办公与技术文档格式：`.pdf`、`.docx`、`.md`（Markdown）以及 `.txt`。
- **单文件上传体积上限**：最大支持 `50MB`；为 0 字节的空文件将被直接拦截并抛出明确提示。
- **递归字符切分参数**：默认切片大小（`chunk_size`）为 `600` 字符，相邻切片重叠窗口（`chunk_overlap`）为 `100` 字符，优先按自然段落、换行符与中文句号进行边界切分。

## 第四节：向量索引与检索阈值说明

为兼顾零外部依赖与检索精度，系统默认搭载本地 TF-IDF 字符级 N-gram 向量化引擎：
- **特征提取范围**：采用字符级 `2~3 gram`（`analyzer="char"`, `ngram_range=(2, 3)`），最大词表特征维度（`max_features`）默认设为 `2048` 维。
- **相关性阈值与拒答保护**：默认最低检索相关度阈值（`min_score_threshold`）为 `0.08`（余弦相似度）。当所有召回片段的余弦相似度均低于 `0.08` 时，系统判定知识库缺乏相关依据，向大模型注入拒答指令，严格要求回答「提供的参考文档中未提及此信息」。

## 第五节：故障排查与错误码字典

运维过程中常见异常代码及处置方案如下：
- **错误码 E1001（API 鉴权失败）**：提示大模型 API Key 无效或额度耗尽。请检查 `.env` 文件中的密钥配置，系统日志会自动对密钥做 `sk-****` 脱敏处理。
- **错误码 E2004（特征维度不匹配）**：通常发生在修改了 `max_features` 参数或跨版本加载旧向量矩阵时。处置方案：执行 `rebuild_index` 命令重新解析文档并覆盖保存 `tfidf_state.pkl` 与 `vectors.npy`。
- **错误码 E3002（无有效文本层）**：用户上传的 PDF 文件为纯图片扫描件或空白页，解析器无法提取任何文字。处置方案：需先经过 OCR 文字识别处理后再行上传。

## 第六节：备份与恢复流程

向量知识库持久化目录位于 `data/vector_db/`，包含以下四个核心文件：`docs.json`、`vectors.npy`、`metadata.json` 与 `tfidf_state.pkl`。
- **自动备份计划**：系统于每日凌晨 `02:00` 自动执行增量快照备份，归档文件存放于 `/data/backup/` 目录。
- **归档保留周期**：历史备份包默认保留 `14` 天，超期归档将由定时任务自动清理。
